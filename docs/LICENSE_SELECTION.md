## 1. Context & Challenge Constraints

---

## 2. License Options

### Option A: MIT License (Recommended for Simplicity)
- **Permissions:** Commercial use, modification, distribution, private use.
- **Conditions:** License and copyright notice must be included in copies.
- **Limitations:** No liability, no warranty.
- **Compatibility:** Fully compliant with hackathon constraints; matches scikit-learn / NumPy / pandas ecosystem.

### Option B: Apache License 2.0 (Recommended for Patent Protection)
- **Permissions:** Commercial use, modification, distribution, patent grants, private use.
- **Conditions:** License and copyright notice, state changes, notice file.
- **Limitations:** Trademark use prohibited, no liability, no warranty.
- **Compatibility:** Fully compliant with hackathon constraints.

## 3. Required Maintainer Information

To finalize the license file, please confirm:
1. **Selected License:** MIT or Apache 2.0
2. **Copyright Holder(s):** Individual names or Team Name (e.g., `Deadly Trio / Urvil Patel`)
3. **Copyright Year:** `2026`
