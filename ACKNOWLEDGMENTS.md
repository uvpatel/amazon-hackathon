# Acknowledgments

We would like to express our gratitude to the following organizations, resources, and open-source communities that made this project possible:

## Competition Organizers
* **Amazon ML Challenge 2026 Organizing Committee**: For formulating a realistic, challenging, and rigorous industrial entity-resolution problem statement, providing large-scale real-world datasets spanning multiple countries and heterogeneous schemas, and supplying the official submission validation suite (`student_resource/utils/validate_submission.py`).

## Open Source Ecosystem
* **Python Software Foundation**: For the Python programming language and standard library (notably `difflib` and `re`).
* **Scikit-Learn Community**: For `sklearn.ensemble.HistGradientBoostingClassifier`, enabling high-performance tree boosting natively handling missing values with zero external C++ runtime dependencies (`libomp`).
* **Pandas & NumPy Developers**: For fundamental high-performance vectorization and tabular data processing libraries.
* **Pytest**: For the testing framework that verifies data integrity and algorithmic correctness across our 32-test automated suite.
