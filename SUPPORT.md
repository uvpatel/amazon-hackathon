## 2. Asking Questions & Reporting Issues

### Search Existing Issues
Before opening a new ticket, search the repository's [GitHub Issues](https://github.com/uvpatel/amazon-hackathon/issues) tab to see if a similar question or bug has already been reported.

### Submitting a Bug Report
When opening a bug report, please provide:
1. **Operating System and Python version** (e.g., macOS Sonoma, Python 3.14.6).
2. **Installed package versions** (`pip list` or `requirements.txt`).
3. **Exact command executed** (including all CLI flags).
4. **Complete traceback and error logs**.
5. **Expected vs. actual behavior**.

### Submitting a Feature or Performance Improvement
For proposed optimizations (e.g., novel blocking keys, feature transformations, or classifier tuning), please open an issue or pull request referencing the relevant section in `docs/` and providing benchmark verification where applicable.
